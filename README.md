# مراجعة وحفظ القرآن — تطبيق PWA

تطبيق ويب تقدمي (PWA) لمراجعة وحفظ القرآن الكريم، يتيح تسجيل تلاوة صوتية مستقلة لكل صفحة من صفحات المصحف (١–٦٠٤)، مع تشغيل غير محدود، تحكم بالسرعة حتى ٢x، وتكرار تلقائي قابل للتخصيص. يعمل بالكامل بدون إنترنت وتُخزَّن جميع التسجيلات محليًا على الجهاز فقط (IndexedDB) — لا يتم رفع أي صوت لأي خادم.

## هيكل الملفات

```
quran-app/
├── index.html          الصفحة الرئيسية وكل عناصر الواجهة
├── manifest.json        بيانات تثبيت التطبيق كـ PWA
├── sw.js                 Service Worker لتفعيل العمل دون إنترنت
├── css/
│   └── style.css         التنسيقات والهوية البصرية
├── js/
│   ├── db.js              طبقة التخزين المحلي (IndexedDB) للتسجيلات
│   └── app.js             منطق التسجيل والتشغيل والتكرار والسرعة
├── icons/                 أيقونات التطبيق (192، 512، وأيقونة قابلة للقص maskable)
├── images/                صور صفحات المصحف (page-<رقم الصفحة>.jpg)
└── tools/
    └── import_pages.py    أداة استيراد صور المصحف من مجلد خارجي دفعة واحدة
```

## إضافة صور صفحات المصحف

كل صفحة في التطبيق تعرض صورة صفحتها من المصحف تلقائيًا إن وُجدت، بالبحث عن ملف باسم:

```
images/page-<رقم الصفحة>.jpg
```

مثال: صفحة سورة الملك الأولى تُعرض من `images/page-562.jpg`. إذا لم توجد الصورة، تظهر رسالة "لم تُضَف صورة هذه الصفحة بعد" دون أي عطل، ويبقى التسجيل والتشغيل يعملان بشكل طبيعي.

**تم تضمين ٢٠ صفحة تجريبية بالفعل (٥٦٢–٥٨١) وهي بداية جزء "تبارك"** — افتح التطبيق واكتب رقم الصفحة ٥٦٢ في حقل التنقل لتجربتها مباشرة.

### استيراد بقية صفحات المصحف (٦٠٤ صفحة) دفعة واحدة

عند توفر مجلد صور لجزء آخر (بنفس ترتيب الملفات المتسلسل كما هو معتاد في مجلدات المصاحف المصوَّرة)، استخدم الأداة المرفقة:

```bash
cd quran-app
python3 tools/import_pages.py /مسار/مجلد/الصور رقم_أول_صفحة_في_المجلد
```

مثال: لو كان لديك مجلد `juz1` يحوي صور الصفحات من ١ إلى ٢١:
```bash
python3 tools/import_pages.py juz1 1
```

تقوم الأداة تلقائيًا بـ:
- ترتيب الملفات أبجديًا وربطها برقم صفحة متسلسل بدءًا من الرقم الذي تحدده
- إعادة تسميتها بالصيغة التي يفهمها التطبيق: `page-<رقم>.jpg`
- ضغط كل صورة وتصغيرها (بحد أقصى ١٠٠٠ بكسل عرضًا) لتبقى سريعة التحميل وموفرة للمساحة دون فقد وضوح النص
- تحتاج مكتبة Pillow: `pip install Pillow` إن لم تكن مثبَّتة

كرّر هذه الخطوة لكل جزء حتى تكتمل الـ٦٠٤ صفحة، ثم أعد تشغيل الخادم المحلي (أو أعد رفع المجلد للاستضافة) ليأخذ Service Worker الصور الجديدة في الكاش تلقائيًا عند أول فتح لكل صفحة.

## طريقة التشغيل

المتصفحات تمنع الوصول إلى الميكروفون وتسجيل الـ Service Worker من مسار `file://` مباشرة، لذلك يجب تشغيل الملفات عبر خادم محلي بسيط (لا يحتاج إنترنت):

### الخيار ١: عبر بايثون (متوفر افتراضيًا على معظم الأجهزة)
```bash
cd quran-app
python3 -m http.server 8080
```
ثم افتح المتصفح على: `http://localhost:8080`

### الخيار ٢: عبر Node.js
```bash
npx serve quran-app -p 8080
```

### الخيار ٣: الاستضافة
ارفع مجلد `quran-app` كما هو إلى أي استضافة ثابتة (GitHub Pages، Netlify، Vercel، أو حتى استضافة عادية بأي شركة). بعد أول فتح للتطبيق مرة واحدة (لتحميل الملفات وتخزينها في الكاش عبر Service Worker)، سيعمل بعدها بدون إنترنت تمامًا، بما في ذلك عند إغلاقه وإعادة فتحه.

## التثبيت كتطبيق (PWA)

- **أندرويد (Chrome):** ستظهر رسالة "إضافة إلى الشاشة الرئيسية" تلقائيًا، أو من قائمة المتصفح ⋮ ← "تثبيت التطبيق".
- **iOS (Safari):** من زر المشاركة ← "إضافة إلى الشاشة الرئيسية".
- **الحاسوب (Chrome/Edge):** ستظهر أيقونة تثبيت ⊕ في شريط العنوان.

## ملاحظات تقنية مهمة

- **التخزين:** كل تسجيل يُحفظ كـ Blob صوتي في IndexedDB مرتبطًا برقم الصفحة — لا حدود زمنية للاستماع، ويبقى محفوظًا بعد إغلاق التطبيق أو إعادة تشغيل الجهاز، إلى أن يحذفه المستخدم يدويًا أو يمسح بيانات المتصفح.
- **جودة الصوت عند تغيير السرعة:** يستخدم التطبيق خاصية `preservesPitch` القياسية في عنصر الصوت، فتبقى نبرة الصوت طبيعية حتى عند التشغيل بسرعة ٢x دون تشويه أو تسريع نغمي (تأثير "الفأر").
- **التكرار التلقائي:** عند اختيار عدد مرات (١، ٢، ٣، ٥، ١٠، ٢٠، ٥٠، ١٠٠) أو "بلا حدود" ∞، تُعاد التلاوة تلقائيًا فور انتهائها حتى اكتمال العدد المطلوب، مع عرض حي لعدد المرات المتبقية حول زر التشغيل.
- **بدون خادم خلفي:** لا يحتوي التطبيق على أي طلبات شبكة إلى خوادم خارجية (لا خطوط من الإنترنت، لا مكتبات CDN) لضمان عمله بشكل كامل دون اتصال منذ أول استخدام.
- **المتصفحات المدعومة:** يعتمد التسجيل على `MediaRecorder API` المتوفر في كل المتصفحات الحديثة (Chrome، Edge، Firefox، Safari 14.1+).
- **تكبير الصورة:** النقر على صورة الصفحة يفتحها بحجم أكبر في صندوق عائم، والنقر عليها مجددًا يغلقه.
- **تذكّر آخر صفحة:** يحفظ التطبيق آخر صفحة فتحتها (عبر localStorage) ويعرضها تلقائيًا عند إعادة الفتح.
- **الأرقام:** جميع الأرقام في الواجهة (رقم الصفحة، الوقت، عدد التكرار) بالأرقام العادية (Western)، وليست بالأرقام العربية-الهندية (١٢٣).

## التخصيص السريع

- عدد الصفحات (افتراضيًا ٦٠٤) قابل للتعديل من ثابت `TOTAL_PAGES` في بداية ملف `js/app.js`.
- الألوان والخطوط قابلة للتعديل من متغيرات `:root` في بداية ملف `css/style.css`.
